## 🌟 مميزات التصميم النظيف والهادئ (Clean & Minimal):
1. **تصميم هادئ ومريح للعين (بدون عجقة أو تعقيد)**:
   - هيدر أنيق وبسيط يحتوي فقط على الروابط الأساسية وزر تبديل اللغة وزر واتساب.
   - قسم رئيسي راقٍ يركز على تخصصك وهويتك الشخصية مع صورتك المرفقة.
2. **معرض الأعمال (24 فيديو إعلاني حقيقي)**:
   - بطاقات عرض عمودية (9:16) مخصصة لمقاطع الموبايل وسوشيال ميديا (تيك توك، ريلز، سناب شات).
   - معاينة سريعة عند تمرير الماوس فوق أي فيديو.
   - مشغل فيديو سينمائي مخصص (Lightbox Modal) بنقرة واحدة مع الصوت وتحكم كامل.
   - فلاتر تصنيف سريعة (الكل 24، مطاعم وأغذية، حلويات، تجميل وعناية، لياقة وجيم، أزياء وموضة، إلكترونيات وجيمنج، خدمات ومناسبات).
   - زر مخصص لكل فيديو لتحويل العميل مباشرة إلى واتساب برسالة جاهزة تطلب إعلاناً مشابهاً لنفس الفيديو بالاسم.
3. **نبذة عن محمود**:
   - نبذة مختصرة عن خلفيتك الأكاديمية (الجامعة الإسلامية بغزة 2026) والخدمات الأساسية.
4. **تواصل مباشر مع العميل**:
   - زر محادثة واتساب مباشر وسريع.
   - نموذج بسيط لإرسال بيانات المشروع مباشرة إلى واتساب.
5. **ثنائي اللغة بالكامل (Bilingual)**:
   - لغة عربية ولغة إنجليزية بضغطة زر واحدة في الهيدر.
